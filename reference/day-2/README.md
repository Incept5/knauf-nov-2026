# Day 2 reference outputs (facilitators)

The Day 2 reference implementations are the packs in `day-2/` themselves; they were run against local models on 2026-11-25 (Apple M5 Max).
`runs/` holds the raw outputs: what a good, and a not so good, answer looks like per model. File prefixes: `q38-27b` is Qwen3.8-27B (mlx_lm.server),
`9b`/`4b` are qwen3.5 via Ollama, `36` is qwen3.6:35b via Ollama (a rough stand-in only; the cluster itself was not called).

# Exercise 5: extend your app from a specification (30 min)

1. Pick the app you built or extended in Exercise 1, 2 or 3 (if you already added the discount in Exercise 2, start again from an unchanged copy or choose another feature).
2. Choose one new feature (suggestion: **a "weekly report" page**, or **a decision box that warns about bad
   delivery days**, or the **5% discount rule from Exercise 2**).
3. Fill in `SPEC-TEMPLATE.md`. Then ask the AI: *"What is missing, ambiguous or contradictory in this specification?"*
   Answer its questions in the spec.
4. Give the agent **only the spec** (plus the repo) and ask it to plan, then implement, then write the tests.
5. Compare with how it went when you added features from a plain prompt (Exercises 2 and 4): what was different?

For POs: do steps 3–4 in a chat window, no terminal needed; an engineer pairs for step 4.
